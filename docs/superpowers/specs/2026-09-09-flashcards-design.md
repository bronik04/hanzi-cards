# Карточки для заучивания слов — дизайн

Дата: 2026-09-09

## Назначение

Небольшое одностраничное HTML-приложение (без сборки, без бэкенда) для заучивания слов по принципу Quizlet: пользователь вставляет таблицу «слово — перевод», приложение превращает её в колоду карточек и предлагает два режима тренировки со свайпами.

## Архитектура

Один самодостаточный HTML-файл: разметка + инлайн CSS + vanilla JS. Без фреймворков и внешних зависимостей — файл можно открыть напрямую в браузере (`file://`) или разместить на любом статическом хостинге.

## Ввод данных

- Textarea на стартовом экране для вставки CSV/TSV.
- Формат: ровно 2 колонки — слово, перевод. Разделитель определяется автоматически (таб, запятая или точка с запятой).
- Если первая строка похожа на заголовок (например «слово,перевод»), она распознаётся и пропускается.
- Пустые строки и строки с некорректным числом колонок пропускаются молча; после разбора показывается сообщение вида «Добавлено N карточек, пропущено M строк».
- Кнопка «Создать колоду» запускает разбор и переводит на экран выбора режима.

## Карточка

- Прямоугольная карточка по центру экрана.
- Клик/тап по карточке переворачивает её (флип-анимация) между лицевой (слово) и обратной (перевод) стороной.
- Свайп работает независимо от того, какая сторона сейчас показана.

## Взаимодействие (свайп)

Единый механизм жестов используется в обоих режимах тренировки:

- Тач-свайп на мобильных устройствах.
- Перетаскивание мышью (drag) на десктопе.
- Стрелки ← / → на клавиатуре как альтернатива.
- Направление: вправо = «знаю», влево = «не знаю».
- Во время перетаскивания карточка подсвечивается цветом (зелёный при движении вправо, красный при движении влево).
- На экране тренировки отображается счётчик прогресса (например, «осталось: N»).

## Режим «Простой просмотр»

- Все карточки колоды участвуют в одном раунде.
- Свайп вправо → карточка убирается из очереди текущего раунда и добавляется в очередь следующего раунда.
- Свайп влево → карточка перемещается в конец очереди текущего раунда (появится снова скоро).
- Когда очередь текущего раунда пуста, начинается следующий раунд из карточек, ушедших «вправо»; номер раунда увеличивается.
- Экран показывает номер текущего раунда и прогресс внутри него.
- Тренировка в этом режиме считается завершённой, когда раунд полностью пройден без карточек, ушедших «влево» (либо когда пользователь явно завершает сессию — простая кнопка «Закончить»/возврат в меню).

## Режим «Заучивание кольцами по 7»

- Колода делится на последовательные блоки по 7 карточек (последний блок может быть короче).
- Блоки проходятся по очереди, один за другим.
- Внутри блока действует тот же свайп-механизм:
  - Вправо → карточка покидает очередь текущего блока.
  - Влево → карточка перемещается в конец очереди текущего блока.
- Блок считается пройденным, когда все его карточки хотя бы один раз ушли «вправо» (очередь блока пуста).
- После того как пройден последний блок, запускается финальный сводный раунд по всей колоде — в логике режима «Простой просмотр» — для закрепления материала.
- Экран показывает номер текущего блока из общего числа блоков и прогресс внутри блока.

## Хранение (localStorage)

- Колода (список слово/перевод) и состояние прогресса (текущий режим, номер раунда/блока, состояние очередей) автоматически сохраняются в localStorage при каждом изменении.
- При открытии страницы, если в localStorage есть сохранённая колода, пользователю предлагается либо продолжить с того места, где остановился, либо загрузить новую таблицу.
- Загрузка новой таблицы требует подтверждения, так как заменяет сохранённую колоду и прогресс.

## Обработка ошибок

- Некорректные строки таблицы пропускаются без остановки разбора, с итоговым сообщением о количестве добавленных/пропущенных строк.
- Пустая колода (0 валидных строк) — кнопка «Создать колоду» неактивна или показывает предупреждение, тренировка не запускается.

## Тестирование

Поскольку это фронтенд-проект без бэкенда, проверка выполняется вручную в браузере (dev-сервер/`file://`):

- Вставка корректной таблицы разных форматов (табуляция, запятая, с заголовком и без) → верное число карточек.
- Вставка таблицы с пустыми/битыми строками → корректный пропуск и сообщение.
- Свайпы мышью, тачем и клавиатурой в обоих режимах → карточки перемещаются по очередям согласно логике.
- Прохождение полного цикла режима «кольца по 7», включая финальный сводный раунд.
- Перезагрузка страницы посреди тренировки → прогресс и колода восстанавливаются из localStorage.
- Загрузка новой таблицы поверх существующей колоды → запрашивается подтверждение.
