# Карточки 汉字

Веб-приложение для заучивания китайских слов на уроке. Преподаватель ведёт
библиотеку именованных колод: у каждой колоды своя таблица
«иероглиф — пиньинь — перевод», своё направление вопроса и своя прерванная
тренировка. Открыл колоду — выбрал направление и режим тренировки, а дальше
листает карточки свайпом; недосмотренную тренировку можно продолжить, вернувшись
в библиотеку и открыв ту же колоду.

Новая колода заводится вставкой таблицы или загрузкой файла (.csv, .tsv, .txt);
имя предлагается заранее, но его можно поменять. Колоду можно переименовать и
удалить из библиотеки. Библиотека целиком сохраняется в файл JSON и
загружается обратно — загрузка добавляет колоды к уже имеющимся, а не заменяет
их; при совпадении имени к нему дописывается номер. Отдельная колода
выгружается таблицей с разделителями-табуляциями и заголовком
`иероглиф	пиньинь	перевод`.

Приложение работает офлайн и ставится на рабочий стол как PWA.

## Разработка

Нужен Node версии из `.nvmrc` (24) или новее: `jsdom` и `vitest` не
работают на Node 20.

```bash
npm install
npm run dev
```

| Команда | Что делает |
|---------|-----------|
| `npm run dev` | Локальный сервер разработки |
| `npm run build` | Сборка в `dist` |
| `npm run preview` | Просмотр собранного приложения |
| `npm run test` | Юнит-тесты и тесты компонентов |
| `npm run test:e2e` | Сквозной тест в браузере |
| `npm run test:e2e:subpath` | Сквозной тест продакшен-сборки под подпутём `/hanzi-cards/` |
| `npm run lint` | ESLint |
| `npm run typecheck` | Проверка типов |
| `npm run icons` | Перегенерация иконок из `public/icon.svg` |

## Устройство

- `src/core` — чистая логика: разбор таблицы, пиньинь, машина состояний
  тренировки, библиотека колод, хранилище и файлы обмена. Не импортирует React
  и не трогает DOM; это правило проверяется ESLint.
- `src/state` — редьюсер и контекст.
- `src/screens`, `src/components`, `src/hooks` — слой представления.
- `src/lib` — то, что обязано трогать DOM и потому не помещается в `core`:
  сохранение файла на диск.

Колоды хранятся целиком под ключом `flashcards.v3`. Ключ `flashcards.v2`
остаётся от Этапа 0 как запасная копия: он читается один раз при переносе и
больше не изменяется.

## Публикация

Приложение живёт по адресу <https://bronik04.github.io/hanzi-cards/> и
обновляется при каждом push в `master`. Workflow Deploy собирает его с
`DEPLOY_BASE=/hanzi-cards/` — без этого пути к ассетам на Pages будут битыми.

Открыв ссылку один раз, приложение можно установить на рабочий стол. Дальше
оно работает без сети: service worker берёт страницу под контроль с первого
же визита, так что офлайн доступен сразу, не дожидаясь повторного открытия.
